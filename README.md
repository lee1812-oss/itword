# 짬짬이 IT 영단어

개발자와 이야기할 때 막히지 않도록, 내가 만든 시스템 속 IT 용어를 반복 학습하는 웹앱(PWA).

- 주소: https://lee1812-oss.github.io/itword/
- 파일: index.html(화면), words.js(단어장), sw.js(오프라인 저장), manifest.webmanifest(설치 정보), icon-*.png
- 학습 기록은 각 기기 브라우저에만 저장됨(설정 > 파일로 내보내기/불러오기)
- 고칠 때: 파일을 바꾼 뒤 sw.js의 VERSION 번호를 올려야 휴대폰이 새 버전을 받음
